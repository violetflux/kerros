# 自動追跡と Selector

Kerros はデフォルトでレンダー中に読み取ったプロパティを自動追跡します。

```tsx
const snapshot = useSettings()
const { profile, save } = snapshot
```

戻り値は現在のレンダー用の読み取り専用追跡スナップショットです。オブジェクト、配列、ネストした読み取りが追跡され、未読フィールドの変更では再レンダーされません。レンダー内のローカル変数に保持したり、custom Hook から返したり、同期的にレンダーされる子コンポーネントへ渡したりできます。変更したり、state、ref、モジュール変数、長期キャッシュにライブな状態として保持したりしないでください。展開、rest 分割、列挙、シリアライズは広範な購読を作ります。

明示的なオブジェクト selector は派生値や計測済みホットスポット向けです。トップレベルフィールドを `Object.is` で比較します。Store 全体は選択しないでください。

アクションも通常の React 値です。React Compiler を使用しない場合は、同一性が重要な箇所で通常の memo 化を利用できます。
