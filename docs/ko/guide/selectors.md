# 자동 추적과 Selector

Kerros는 기본적으로 렌더링 중 읽은 속성을 자동 추적합니다.

```tsx
const snapshot = useSettings()
const { profile, save } = snapshot
```

반환값은 현재 렌더의 읽기 전용 추적 스냅샷입니다. 객체, 배열, 중첩 속성 읽기가 추적되며 읽지 않은 필드 변경은 다시 렌더링하지 않습니다. 렌더 로컬 변수에 보관하거나 custom Hook에서 반환하거나 동기적으로 렌더링되는 자식 컴포넌트에 전달할 수 있습니다. 스냅샷을 수정하거나 state, ref, 모듈 변수, 장기 캐시에 실시간 상태처럼 보관하지 마세요. 펼치기, rest 구조 분해, 열거, 직렬화는 넓은 구독을 만듭니다.

React Element와 Portal은 자동으로 원자 값으로 처리됩니다. React 17, 18, 19에서 표준 `useRef()`와 `createRef()` 컨테이너는 그대로 반환할 수 있습니다. Proxy를 허용하지 않는 서드파티 객체이거나 엄격한 객체 동일성을 유지해야 할 때만 `ref(value)`를 사용하세요. 원자 값의 내부 변경은 반응형이 아니므로 렌더링이 필요하면 새 참조를 게시해야 합니다.

명시적 객체 selector는 파생 값과 측정된 핫스팟을 위한 고급 경로입니다. 최상위 필드는 `Object.is`로 비교합니다. Store 전체를 선택하지 마세요.

액션은 일반 React 값입니다. React Compiler를 사용하지 않는다면 동일성이 중요한 곳에서 일반적인 memo 도구를 사용할 수 있습니다.
